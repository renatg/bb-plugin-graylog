# Плагин Graylog для BB

В левой навигации BB есть страница **Graylog**:

- окружение (общее для Jaeger и Graylog), блок «Найти TraceId в Jaeger»;
- **Поиск** по TraceId или по описанию — только находит и показывает логи, без анализа;
- под логами «Продолжить с агентом» — вопрос создаёт скрытый тред с найденными логами;
- слева история поисков, сгруппированная по окружениям.

Треды, созданные плагином, начинаются с сообщения «Логи Graylog. Окружение: …»:
там окружение, instance, stream, запрос и найденные сообщения (с телами запросов,
обрезанными до 4000 символов). За полными текстами обращайся к MCP graylog
(`get_message` с указанными instance, index и id). Для stage передавай instance `hotfix`.
